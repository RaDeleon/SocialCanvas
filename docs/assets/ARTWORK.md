# SocialCanvas artwork

The named illustrated banner uses a playful red panda arranging floating photo tiles and feed layouts in a layered-paper world. It follows the owner’s rich illustration standard while giving SocialCanvas its own setting and visual metaphor. No desk, window or lamp props are used.

The banner is conceptual product artwork, not a live Instagram account, a screenshot, a usage report or a claim that image generation is part of the application. The existing dashboard image remains an actual application screenshot using labeled sample photography.

The earlier SVG banner is retained as source history; the README and portfolio use the named PNG. This presentation update does not change the application, OAuth permissions or deployment.
